# Python 3.10 or newer.
#
# FLOORS, NOT EXACT PINS - deliberately.
#
# A client machine has whatever Python their IT installed, usually 3.10 or
# 3.11, rarely the newest. Exact pins would simply refuse to install there.
# With floors, pip resolves the newest version that works on the Python it
# finds: duckdb 2.x on 3.11+, duckdb 1.4.x on 3.10. Upper bounds only where a
# future MAJOR version could plausibly break us.
#
# The trade is that two machines can resolve different versions. The current
# way to re-measure on a new machine is `python benchmark.py` (see SETUP.md);
# the old verify.py it replaced belonged to an earlier generation and is gone.
#
# Built and tested on Python 3.14.7 with duckdb 2.0.0 and
# pytest 9.2.0.
#
# Licences are listed because this ships to clients. No GPL/AGPL.

# ---- required to run what exists today -------------------------------------
duckdb>=1.4,<3             # MIT    - embedded engine, no server to install
PyYAML>=6.0,<7             # MIT    - run.py's startup guard checks it; no YAML
                           #          file is read by the current code yet
pytest>=8.0,<10            # MIT    - the tests (on 9.2.0)

# ---- optional: extra formats and cloud connectors --------------------------

# source is used. Add them only if you need that source.
