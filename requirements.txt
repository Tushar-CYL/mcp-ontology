# Python 3.10 or newer.
#
# FLOORS, NOT EXACT PINS - deliberately.
#
# A client machine has whatever Python their IT installed, usually 3.10 or
# 3.11, rarely the newest. Exact pins would simply refuse to install there.
# With floors, pip resolves the newest version that works on the Python it
# finds: duckdb 2.x on 3.11+, duckdb 1.4.x on 3.10; networkx 3.7 on 3.12+,
# networkx 3.4.2 on 3.10. Upper bounds only where a future MAJOR version
# could plausibly break us.
#
# The trade is that two machines can resolve different versions. That is
# what `python verify.py` is for - run it after installing anywhere new and
# it re-measures every number, so version drift shows up as a failed check
# rather than a wrong answer months later.
#
# Built and tested on Python 3.14 with duckdb 2.0.0 and networkx 3.7.
#
# Licences are listed because this ships to clients. No GPL/AGPL.
